> **Nota sobre como este exemplo foi produzido:** a conta usada para testar o
> projeto ficou sem crédito de API no momento de gerar os exemplos, então
> esta conversa foi **escrita à mão** (não é uma transcrição bruta de uma
> chamada real ao `claude-sonnet-5`) — mas com base em saídas reais das
> ferramentas do agente (`search_products`, `get_product_by_name`), rodadas
> de verdade contra `data/products.csv` neste projeto. Ver README > "Uso de
> assistentes de IA" para os detalhes.
